DÉTOUR WEBSITE — FIRST VERSION

Files:
- index.html: homepage content and partner links
- style.css: responsive layout and styling

UPLOAD TO GITHUB:
1. Open https://github.com/bikepackerbrussels/detour-website
2. Choose Add file > Upload files.
3. Unzip this archive on your computer.
4. Drag index.html and style.css into the upload area (not the enclosing folder).
5. Commit changes to the main branch.

IMPORTANT:
- The homepage is intended for https://detour.brussels/
- Images are currently referenced from the original Squarespace CDN, rather than copied into this repository. This keeps this first version small, but means the original image URLs must remain available.
- The partner logos and text were taken from the authorised source page. Check the visual result before connecting the custom domain.
- The Cobble card uses a text wordmark because no separate Cobble logo image was exposed in the page's image links.
- This is a first visual reproduction, not a pixel-perfect clone. Fine adjustments can be made after comparing it with the original page in a browser.
